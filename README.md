# RentOS

## Rent Operating System

RentOS es una plataforma SaaS multiempresa diseñada para la administración
integral de empresas de alquiler de vehículos (Rent Cars).

## Objetivo

Proporcionar a cada Rent Car un espacio independiente para gestionar su
operación, incluyendo vehículos, clientes, reservas, empleados, pagos,
mantenimiento y otros procesos relacionados con el alquiler de vehículos.

## Características principales previstas

- Gestión multiempresa.
- Registro y aprobación de Rent Cars.
- Administración de usuarios y roles.
- Gestión de vehículos.
- Estados y disponibilidad de vehículos.
- Gestión de clientes.
- Gestión de reservas.
- Pagos y depósitos.
- Contratos.
- Mantenimiento.
- Inspecciones y daños.
- Reportes.
- Personalización por Rent Car.
- Integración futura con sistemas GPS.
- Página pública futura.
- Aplicación móvil futura.
- Red RentOS futura para colaboración entre Rent Cars.

## Tecnologías

- npm
- Git
